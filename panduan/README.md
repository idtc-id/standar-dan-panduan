# Panduan & Framework

**Guideline** berisi panduan praktis cara menerapkan. **Framework** berisi kerangka berpikir,
klasifikasi, atau tingkat kematangan. Keduanya bersifat anjuran, bukan ketentuan wajib.

Setiap dokumen menempati satu folder: `DT-G-<nomor>-<slug>/` atau `DT-F-<nomor>-<slug>/`.
Gunakan [template dokumen standar](../template/dokumen-standar.md).
