# Standar & Panduan Digital Twin Indonesia

Dokumen resmi yang diterbitkan **Pokja 1 IDTC**: standar, guideline, framework, dan policy brief
untuk penerapan Digital Twin di Indonesia.

> **Repo ini baru dimulai.** Belum ada dokumen berstatus *Berlaku*. Cara kerja penyusunannya
> ada di [`pokja1-handbook`](https://github.com/idtc-id/pokja1-handbook).

Mulai dari [**DT-F-01 — Kerangka Klasifikasi Standar Digital Twin Indonesia**](panduan/DT-F-01-klasifikasi-standar/):
kerangka lima lapisan yang menjadi peta kerja seluruh dokumen di repo ini.

## Memberi masukan

- **Masukan umum atau pertanyaan** → tab **Discussions**.
- **Usulan perubahan kalimat tertentu** → buka file → ✏️ → ajukan Pull Request.
- **Usulan topik dokumen baru** → buat issue di
  [`pokja1-handbook`](https://github.com/idtc-id/pokja1-handbook/issues).

Sebutkan **kode dokumen dan nomor bagian** yang Anda komentari.

## Struktur folder

```
standar/          Dokumen normatif (ketentuan teknis)
panduan/          Guideline & framework (anjuran, kerangka acuan)
policy-brief/     Rekomendasi kebijakan
template/         Template penulisan dokumen
```

Setiap dokumen menempati satu folder sendiri, misalnya
`standar/DT-S-01-glosarium/` berisi `README.md` (naskah), lampiran, dan contoh.

## Penomoran kode dokumen

```
DT-<jenis>-<nomor urut>
```

| Jenis | Kode |
|---|---|
| Standar | `S` |
| Guideline | `G` |
| Framework | `F` |
| Policy brief | `P` |

Contoh: `DT-S-01`, `DT-G-03`, `DT-P-02`.
